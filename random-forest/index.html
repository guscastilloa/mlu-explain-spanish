El algoritmo de Bosques Aleatorios

Cómo la mayoría de los votos y el azar bien utilizado pueden mejorar el modelo de árbol de decisión.

Por Jenny Yeon, Jared Wilber & Gustavo A. Castillo-Alvarez (trad.)





Pero primero: Un teorema de 1785

Hace mucho tiempo en el año 1785, el Marqués de Condorcet expresó un teorema de ciencia política sobre la probabilidad relativa de un grupo de individuos que llega a una decisión mayoritaria correcta.

A pesar de su edad, el teorema ha sido aplicado a una variedad de campos, principalmente para nosotros en el campo del machine learning. Para ver cómo, comencemos con un modelo, un árbol de decisión con una precisión del 60%.

El teorema del Jurado de Condorcet dice que si cada persona está más del 50% en lo correcto, entonces agregar más personas para votar aumenta la probabilidad de que la mayoría agregada esté en lo correcto.

De acuerdo con el teorema, si le preguntamos a dos árboles de decisión más, cada uno con una precisión del 60%, y tomamos una decisión mediante voto por mayoría, entonces la probabilidad de que el voto sea correcto aumenta al 65%!

El teorema sugiere que la probabilidad de que el voto mayoritario sea correcto puede aumentar a medida que agregamos más y más modelos. Con once modelos, la mayoría puede llegar a un 75% de precisión!

Hay un matiz. La precisión puede no mejorar si cada modelo produce la misma predicción, por ejemplo. El error de un modelo no sería capturado por los otros modelos. Por lo tanto, querríamos usar el voto mayoritario utilizando los modelos que son diferentes.

Podemos agregar más y más modelos.

Juega con los deslizadores tú mismo! El superior controla el número de árboles en el conjunto (también llamado ensamble). El inferior controla la precisión de cada árbol.

En machine learning, este concepto de múltiples modelos trabajando juntos para llegar a una predicción agregada se llama aprendizaje en conjunto o ensemble learning. Proporciona la base para muchos importantes modelos de machine learning, incluyendo los bosques aleatorios.

Aprendizaje en conjunto

El aprendizaje en conjunto crea un modelo más fuerte al agregar las predicciones de múltiples modelos débiles (o weak learners), tales como árboles de decisión (revisa nuestro artículo sobre Árboles de Decisión para aprender más sobre algunas de sus limitaciones). El teorema del Jurado de Condorcet sugiere que la agregación mediante voto mayoritario puede tener mejor precisión que los modelos individuales. Hay otros métodos para agregar predicciones, como el voto mayoritario ponderado.


El Bosque Aleatorio es un ejemplo de aprendizaje en conjunto donde cada modelo es un árbol de decisión. En la siguiente sección, construiremos un modelo de bosque aleatorio para clasificar si una señal de tráfico es una señal de cruce peatonal o no. Estas señales vienen en muchas variaciones, y utilizaremos cuatro características simples: Tamaño, número de lados, número de colores utilizados y si la señal tiene texto o símbolo.

Comenzaremos con un método de muestreo llamado el Método de Bagging para crear múltiples muestras a partir de los datos de entrenamiento para construir cada árbol.

Bosque Aleatorio

Método Bagging

Una forma de producir múltiples modelos diferentes es entrenar cada modelo utilizando un conjunto de entrenamiento diferente. El método Bagging (Bootstrap Aggregating) selecciona aleatoriamente un número fijo de muestras del conjunto de entrenamiento con reemplazo. Esto significa que una observación (data point) puede ser seleccionado más de una vez.

Esto da como resultado varios conjuntos de entrenamiento que son diferentes. Aquí, tenemos tres muestras. Observa que algunos puntos de datos se comparten entre algunas muestras. Cada muestra luego puede ser utilizada para construir un modelo. ¡Construyamos algunos árboles de decisión con estas muestras!

Selección de Características

Aquí están las características: Tamaño, Número de Lados, Número de Colores Utilizados y Texto o Símbolo.

Para cada división en la construcción del árbol, calculamos la mejor división utilizando solo un subconjunto seleccionado aleatoriamente de las características. Esta es otra forma de garantizar que los árboles de decisión sean lo más diferentes posible.

Construyamos el primer árbol con la primera muestra! Para la primera partición, tres predictores son seleccionados para encontrar la mejor partición.

El mejor predictor para la partición es "Número de Colores Utilizados"

Asimismo, para la segunda partición, otro conjunto de predictores son seleccionados para encontrar la mejor partición. El mejor predictor para la partición esta vez es "Texto o Símbolo"

Este proceso continúa hasta que el árbol es construido. Las demás muestras servirán para construir otros árboles usando el mismo proceso.

Varianza en la Composición


Anteriormente discutimos cómo el modelo de árbol de decisión sufre de alta varianza. Sin embargo, esta varianza entre los árboles se emplea en el bosque aleatorio como una característica, no como un error. Leo Breiman, el inventor del modelo de bosque aleatorio dice en su artículo "[n]uestros resultados indican que los mejores bosques aleatorios (con menor error de generalización) tienen menor correlación entre clasificadores y mayor fuerza." [Artículo de Bosque Aleatorio]

La alta varianza del modelo de árbol de decisión puede ayudar a mantener baja la correlación entre los árboles. El Método de Bagging así como la seleccion de predictores (feature selection) son las innovaciones clave para mantener baja la correlación.

Acabamos de mostrar cómo construir bosques aleatorios para un conjunto de datos dado, pero ¿qué tan diferentes son nuestros árboles entre sí en realidad? Para averiguarlo, hemos entrenado un bosque aleatorio de nueve árboles en nuestro conjunto de datos de señalización de tránsito y lo hemos graficado a continuación.

El círculo exterior representa el bosque aleatorio. Cada círculo interior representa un árbol de decisión único en el bosque. Al pasar el cursor sobre un árbol se resaltará la precisión de clasificación del árbol y sus importancias de características* para cuatro características.




Observa que cada árbol tiene una combinación bastante única de importancias de predictores y precisión, y no hay un patrón obvio. Algunos árboles solo usan dos de las cuatro características, y el árbol con importancias de características similares al modelo de bosque aleatorio aún tiene un rendimiento mucho peor que el bosque. Como se discutió en el teorema de Condorcet, la conclusión clave es el poder que estos modelos emplean cuando se agregan juntos de manera inteligente, como lo demuestra el modelo de bosque aleatorio que tiene la precisión más alta.


Como era de esperar, el modelo de bosque aleatorio (los puntos rojos a la derecha) tiene un mejor rendimiento que cualquier árbol individual. Observa el amplio rango de los puntajes de importancia de características en nuestros árboles, lo que puede contribuir a una baja correlación. En la primera herramienta de visualización de bosque aleatorio desarrollada por Breiman, él también intentó mostrar el rango en las importancias de características.

Varianza en las Predicciones


Si cada árbol produce la misma predicción, entonces la precisión no puede mejorar. A continuación, cada círculo representa una predicción de un modelo. Los círculos en la misma fila comparten el mismo modelo, mientras que los círculos en la misma columna comparten los mismos datos de prueba. Azul significa "Sí" y rosa significa "No". El color sólido significa que la predicción es correcta, mientras que la franja significa que la predicción es incorrecta. No se muestran todos los datos de prueba.

El patrón irregular en la cuadrícula muestra cómo los árboles son diferentes en dónde cometen errores. Como era de esperar, el modelo de bosque aleatorio tiene el mejor rendimiento general incluso si hay árboles con muy baja precisión. Observa que para el primer dato (primera columna), todavía hay tres árboles con la predicción correcta mientras que la mayoría es incorrecta. Esto inspiró a la gente a considerar otros métodos, como el Boosting, que es muy popular hoy en día.

Conclusión

Los modelos de Bosque Aleatorio son un modelo popular para una gran cantidad de tareas. En resumen, es un método para producir predicciones agregadas usando las predicciones de varios árboles de decisión. El antiguo teorema de Condorcet sugiere que el voto mayoritario de varios modelos débiles con más del 50% de precisión puede funcionar. Más tarde, Breiman desarrolló el Bagging y la Selección de Características/predictores (feature selection) que ayuda a mantener baja la correlación entre los árboles, lo cual es clave para el éxito.

Se ha desarrollado alguna teoría alrededor del sesgo y la varianza del modelo de bosque aleatorio en relación con los árboles que tiene. Consulta este artículo sobre el dilema entre sesgo y varianza para aprender más sobre estos conceptos.
